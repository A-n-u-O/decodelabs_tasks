# DecodeLabs Backend Development - Project 2

## Database Integration (CRUD API)

A REST API built with Node.js and Express that demonstrates database integration and CRUD operations using PostgreSQL and Prisma ORM.

The API allows users to be created, retrieved, updated, and deleted while providing input validation, duplicate email prevention, and persistent data storage.

## Features

- Create a user
- Retrieve all users
- Retrieve a user by ID
- Update a user
- Delete a user
- Prevent duplicate email addresses
- Validate user input
- PostgreSQL data persistence
- Express middleware for user ID validation

## Technologies Used

- Node.js
- Express.js
- PostgreSQL
- Prisma ORM
- JavaScript
- Postman
