# DecodeLabs Backend Projects

A collection of backend development projects completed during my DecodeLabs internship, progressing from REST API fundamentals to database-backed CRUD, authentication, and third-party API integration.

## Projects

### Project 1 — REST API Fundamentals

Built a basic REST API with Node.js and Express.js to understand server-side routing, request/response handling, validation, and HTTP status codes.

Key concepts:
- Express routing
- `GET` and `POST` endpoints
- JSON request bodies
- Validation
- Duplicate prevention
- 404 handling
- HTTP status codes
- Postman testing

---

### Project 2 — PostgreSQL CRUD API

Built a persistent CRUD API using PostgreSQL and Prisma ORM.

Key concepts:
- PostgreSQL database integration
- Prisma ORM
- Create, read, update, and delete operations
- Unique constraints
- Input validation
- Reusable middleware
- Persistent data storage
- Postman API testing

---

### Project 3 — Authentication System

Built an authentication API with secure password storage and protected routes.

Key concepts:
- User registration and login
- Argon2 password hashing
- JWT authentication
- Bearer tokens
- Authentication middleware
- Protected routes
- Environment variables
- Generic authentication error responses
- PostgreSQL and Prisma integration

---

### Project 4 — Third-Party API Integration

Built a weather API endpoint that integrates with an external weather service using Axios.

Key concepts:
- Third-party API integration
- Axios
- Environment-based configuration
- Query parameters
- Response transformation
- Timeout handling
- Upstream API error handling
- Safe error logging
- HTTP 502 and 504 responses

## Tech Stack

- Node.js
- Express.js
- JavaScript
- PostgreSQL
- Prisma ORM
- JWT
- Argon2
- Axios
- Postman
