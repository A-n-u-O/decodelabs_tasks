# DecodeLabs Backend Development Internship

This repository contains backend development projects completed during my DecodeLabs internship.

## Projects

### Project 1 — REST API Basics
Built a REST API with Node.js and Express.js, covering routing, HTTP methods, validation, status codes, duplicate prevention, and error handling.

### Project 2 — Database Integration (CRUD API)
Built a persistent CRUD API using Node.js, Express.js, PostgreSQL, and Prisma ORM.

### Project 3 — Secure Authentication System
Implemented user registration and login with Argon2 password hashing, JWT authentication, middleware, and protected routes.

### Project 4 — Third-Party API Integration
Integrated WeatherAPI using Axios, environment variables, response transformation, timeouts, and graceful third-party error handling.

## Technologies

Node.js • Express.js • JavaScript • PostgreSQL • Prisma ORM • Argon2 • JWT • Axios • Postman
